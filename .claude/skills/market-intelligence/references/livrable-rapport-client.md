# MODE A — Rapport Client : Structure & Templates

### ═══ MODE A : RAPPORT CLIENT ═══

Structure en 7 sections. Ton : stratégique, narratif, prescriptif.
Le client doit pouvoir lire ce rapport sans expertise marketing.

---

#### SECTION 0 : Page de Garde & Contexte

```markdown
# Analyse de Marché — [Secteur / Offre]
**Préparé par :** [Nom / MBScaling]
**Date :** [Date]
**Client :** [Nom client si applicable]
**Périmètre :** [Marché analysé, géographie, période]

---

## Contexte & Objectifs de l'Analyse

[2-3 paragraphes : pourquoi cette analyse, quelle décision elle doit éclairer,
quelle question stratégique elle répond]
```

---

#### SECTION 1 : Executive Summary (1 page maximum)

C'est la section la plus importante. Un dirigeant pressé doit pouvoir prendre une décision stratégique à partir de cette seule page.

Structure obligatoire :

```markdown
## Executive Summary

### Le marché en 3 chiffres
→ [Chiffre 1 — taille/volume] : [interprétation en 1 phrase]
→ [Chiffre 2 — croissance/tension] : [interprétation]
→ [Chiffre 3 — benchmark critique] : [interprétation]

### L'insight central
[1 paragraphe. La vérité contre-intuitive ou la tension principale que révèle l'analyse.
Ce n'est pas un résumé — c'est le "so what" stratégique.]

### Les 3 recommandations prioritaires
1. **[Recommandation 1]** — [Justification courte] → Impact estimé : [Élevé/Moyen/Faible]
2. **[Recommandation 2]** — [Justification courte] → Impact estimé : [...]
3. **[Recommandation 3]** — [Justification courte] → Impact estimé : [...]

### Risques à surveiller
→ [Risque 1]
→ [Risque 2]
```
