# Règles de Jeu, Ton & Patterns de Script Validés

Extraits et patterns issus des productions validées.
À lire pour caler le ton exact avant de rédiger le script.

---

## LE TON QUI MARCHE — Par format

### UGC Lifestyle / Témoignage personnel

**Voix :** Première personne. "Moi j'ai cherché..." / "On m'a parlé de..."
**Registre :** Familier sans être vulgaire. Proche café du commerce.
**Rythme :** Phrases courtes. Pas de subordonnées longues.
**Humour :** Autodérision légère. Pas de blague forcée.

```
✅ MARCHE :
"Heureusement que je l'ai faite cette simulation !"
"Honnêtement ? Un conseil d'un expert gratuit ça se refuse pas."
"Ou alors d'acheter des lingots mais bon…"
"Bon si je réussis vous faites la simulation gratuite ?"

❌ NE MARCHE PAS :
"Je vous encourage vivement à vous renseigner sur..."
"Il convient de noter que ce produit présente plusieurs avantages..."
"N'hésitez pas à consulter notre plateforme pour..."
```

### Podcast Interview

**Voix :** Naturel, réponse à une vraie question.
**Registre :** Expert accessible. Comme si on expliquait à un ami.
**Marqueurs d'authenticité :** "En fait...", "Ah bah là...", "Oui, exactement"
**Rires :** Présents dans le script — ne pas les couper.

```
✅ MARCHE :
"Oui en fait." (ouverture neutre, brise l'intro artificielle)
"Ah bah là tu commences à poser les bonnes questions ! *(rire)*"
"Ils sont forts ces luxembourgeois !"
"Et après tout ce que je te dis là c'est un conseiller qui me l'a dit..."

❌ NE MARCHE PAS :
"Excellente question ! Je vais vous expliquer..."
"Effectivement, comme vous le soulignez très justement..."
"Permettez-moi de développer ce point important..."
```

### Expert Bureau

**Voix :** Professionnel qui "trahit" un secret à ses pairs.
**Registre :** Connivence. "Entre nous, voilà ce que je dis vraiment à mes clients."
**Humour :** Discret, sourire, clin d'œil. Jamais lourd.
**Chute :** Action physique (clin d'œil, sourire face caméra).

```
✅ MARCHE :
"*(en se moquant un peu)* Et puis quand on me demande..."
"Y'a vraiment rien à perdre."
"Si tu veux protéger ton patrimoine, je te conseille de cliquer directement."
"*(fait un clin d'œil à la caméra)*"

❌ NE MARCHE PAS :
"En tant que professionnel certifié, je vous recommande..."
"Notre offre vous permet de bénéficier d'avantages significatifs..."
```

## PATTERNS D'ACCROCHE VALIDÉS

### Pattern 1 — Question Directe + Révélation

Structure : Question qui cible → Révélation surprenante → Implication

```
EXEMPLE :
"Vous avez plus de 250 000 euros de côté ?
En cas de crise, vous pouvez perdre bien plus que vous ne le pensez."

VARIABLES :
"Vous avez des placements financiers ?"
"Vous voulez investir votre patrimoine mais vous ne savez pas où ?"
"Vous saviez qu'en France en cas de crise [X] ?"
```

### Pattern 2 — Révélation Choc (sans question)

Structure : Affirmation contre-intuitive → preuve → impact

```
EXEMPLE :
"Peu de gens le savent mais l'assurance vie en France peut être dangereuse !
Y a la loi Sapin 2 qui permet à l'État de bloquer vos retraits à tout moment."

VARIABLES :
"Beaucoup l'ignorent mais l'État peut légalement bloquer vos retraits !"
"Ce que peu de gens savent, c'est que vous pouvez tout perdre en un claquement de doigt."
```

### Pattern 3 — Identification + Repositionnement Mental

Structure : "Les gens comme vous" → question différente → solution

```
EXEMPLE :
"Aujourd'hui, les gens qui ont plus de 250k à investir,
il ne se posent plus la question 'comment s'enrichir ?'
mais 'comment se protéger ?'"

VARIABLES :
"Les Français qui ont réussi à protéger leur épargne ne font pas ce que vous croyez."
"Ceux qui dorment sur leurs deux oreilles ont tous fait une chose en commun."
```

### Pattern 4 — Contexte Géopolitique + Urgence

Structure : Contexte actuel → risque personnel → solution

```
EXEMPLE :
"Dans le contexte géopolitique actuel est-ce que vous êtes certains
que votre épargne est à l'abri ?"

VARIABLES :
"Dans le contexte actuel vous croyez que votre épargne est vraiment à l'abri ?"
"Vu ce qui se passe en ce moment, votre argent est vraiment en sécurité ?"
```

## PATTERNS DE CTA INTÉGRÉ (naturel)

Le CTA ne doit jamais sembler collé. Il découle du discours.

### CTA par la recommandation personnelle
```
"Ce que je conseille toujours c'est de faire sa simulation sur [produit]."
"J'ai juste fait ma simulation gratuite de 2 minutes sur [produit]."
"Ce que je conseille toujours à mes clients c'est [produit]."
```

### CTA par la preuve d'expérience
```
"Et après ça, un conseiller en gestion de patrimoine m'a appelé."
"Y'a même un expert en gestion de patrimoine qui m'a contacté pour me conseiller."
"Et derrière, un conseiller vous contacte pour vous aider à faire les bons choix."
```

### CTA par la logique imparable
```
"Si tu peux avoir des conseils d'un expert gratuitement, pourquoi s'en priver finalement ?"
"Quand c'est gratuit ça se refuse pas !"
"Y'a vraiment rien à perdre."
"Comprendre comment votre argent est protégé… Ça ne coûte rien."
```

### CTA avec chute humoristique
```
"Bon si je réussis [action physique], vous faites la simulation gratuite ?"
"Heureusement que je l'ai faite cette simulation ! Faites-le, je vous le dis !"
"Ou alors d'acheter des lingots mais bon…"
"Que demande le peuple ?!"
```

## MÉTAPHORES PHYSIQUES VALIDÉES PAR ACTIVITÉ

### Golf
```
Setup balle = "Se préparer avant d'agir" / "Prendre le temps d'analyser"
Swing raté = "Sans méthode, on rate" / "Pas prêt = mauvais résultat"
Swing réussi = "Avec la bonne méthode" / "En 2 minutes"
Balle dans le trou = "Le résultat parfait" / "Ce que vous voulez obtenir"
Marcher vers le trou = "Le chemin vers la solution"
```

### Billard
```
Casse initiale = "Lancer le process" / "Commencer maintenant"
Boule bien placée = "Stratégie précise"
Mettre 2 boules d'un tir = "Efficacité" / "Gain de temps"
Boule noire = "La dernière étape" / "Le résultat final"
Rater un coup = "Sans méthode / sans outil"
```

### Jardinage
```
Tailler les branches = "Optimiser / éliminer ce qui ne sert pas"
Planter = "Construire sur le long terme"
Prendre une pelle / creuser = "Pas besoin d'enterrer son argent"
Jardin bien entretenu = "Patrimoine bien géré"
"Comme ce jardin" = comparaison directe avec la protection
```

### Grande Maison
```
Regarder la maison = "Ce qu'on peut obtenir / protéger"
Partir sans se retourner = "Confiance dans la décision prise"
Façade propre = "Image de la réussite"
```

## INDICATIONS DE JEU — Glossaire Terrain

Chaque indication dans le script correspond à une instruction précise pour l'acteur.

```
*(rire)*
→ Rire naturel, pas forcé. Si l'acteur ne rit pas naturellement : garder quand même
   et couper au montage. Ne pas rejouer un rire.

*(nonchalant)*
→ Détendu, sans énergie excessive. Comme si c'était évident.
   Regarder légèrement de côté ou au loin.

*(se gratte derrière la nuque, fatigué)*
→ Geste physique précis. L'acteur le fait PENDANT qu'il dit la phrase
   ou juste après (pas avant).

*(regarde la maison)* / *(regarde le trou)*
→ Regard OFF caméra dans la direction indiquée. 1-2 secondes. 
   Puis retour caméra ou fin du plan.

*(part sans se retourner)*
→ L'acteur finit sa phrase, puis se retourne et s'éloigne calmement.
   La caméra reste fixe et le suit jusqu'à ce qu'il soit hors champ.

*(fait un clin d'œil à la caméra)*
→ Naturel, une seule fois. Exagéré si répété. Sourire post-clin d'œil = OK.

*(prend une pelle pour creuser un trou)*
→ Action physique complète. L'acteur saisit l'outil, fait le geste.
   Plan s'arrête sur le geste ou sur la réaction de l'acteur.

*(pose la balle)* / *(swing)*
→ Action golf séquencée. Filmer en plan latéral ET en plan face.
   Le texte est dit AVANT le swing, jamais pendant.

*(se place devant la balle)* / *(tire sur sa balle)*
→ Idem golf. La tension de "va-t-il réussir" est le moteur de la fin.

*(plan: met un gros coup)*
→ Billard. L'acteur joue normalement. On garde la prise même si la boule rate.
   L'acteur réagit de toute façon (sourire, surprise).
```

## ERREURS FRÉQUENTES À BRIEFER À L'ACTEUR

```
❌ Regarder les notes / le télésouffleur de façon trop évidente
   → Mémoriser les grandes lignes, improviser autour. Pas le texte mot pour mot.

❌ Commencer à parler trop vite après "action"
   → Attendre 1 seconde. Respirer. Puis commencer.

❌ Baisser le regard à la fin des phrases
   → Garder le regard caméra jusqu'à la fin du plan. Le monteur coupe, pas l'acteur.

❌ Rejouer les émotions (rire forcé, surprise jouée)
   → Les vraies réactions > les réactions jouées. Favoriser les situations réelles.

❌ Mouvement de tête en parlant (hochement, non)
   → Immobilité de la tête sauf intention précise. Le mouvement doit être discret.

❌ Voix qui monte en fin de phrase (intonation question sur affirmation)
   → Phrase affirmative = voix qui descend légèrement en fin. À corriger dès la prise 1.

❌ Débit trop rapide pour compenser la nervosité
   → Rappeler : les silences vendent. Une pause de 0.5s = emphase.
   → Dire à l'acteur de parler comme s'il expliquait à son meilleur ami.
```

## EXEMPLE DE BRIEF ACTEUR (à donner le jour J)

```
BRIEF ACTEUR — [Prénom]

AUJOURD'HUI TU JOUES : [Toi-même / Un expert / Un ami qui conseille]

TON : [Décontracté et sympathique / Expert accessible / Posé et sage]

CE QU'ON CHERCHE :
→ Naturel avant tout. Si tu rates une phrase, recommence sans s'arrêter.
→ L'activité (golf / jardinage / billard) est vraie — fais-la vraiment.
→ Parle à ton meilleur ami qui est derrière la caméra.
→ Tu n'es pas en train de faire une pub — tu partages quelque chose d'utile.

LES MOMENTS CLÉS :
→ L'accroche (0-5s) = énergie maximale, regard caméra direct
→ Le développement = plus posé, peut regarder légèrement de côté
→ Le CTA = sourire, regard caméra, ton de "conseil entre amis"
→ La chute = la meilleure prise = la plus naturelle, même si tu ris

TEXTE :
→ Tu n'as pas à le répéter mot pour mot.
→ Les grandes idées importantes : [lister 5-6 points clés]
→ Les mots exacts obligatoires : [nom du produit, URL, chiffres clés]
→ Le reste : improvise autour.

ON TOURNE [N] VIDÉOS AUJOURD'HUI :
[Liste avec durée estimée par vidéo]

PLANNING :
[Heure début / ordre des vidéos / pauses]
```
