# Formats, Décors & Checklist Matériel

Référence complète des spécifications techniques par type de décor et de format.
Inclut les checklists matériel, les règles de cadrage et les pièges terrain à éviter.

---

## DÉCORS VALIDÉS & LEURS SPÉCIFICITÉS

### Extérieur — Grande Maison / Villa

**Ambiance cible :** Aspirationnel, réussite discrète, patrimoine visible
**Moment de tournage idéal :** Golden hour (1h avant coucher soleil) ou matin 8h-10h
**Ce qu'on voit :** Façade propre, jardin entretenu, voiture si adaptée

```
CADRAGE RECOMMANDÉ :
- Plan large établissement : acteur marche vers caméra, maison en fond
- Plan moyen : devant la porte / terrasse / bord de piscine
- Plan rapproché : épaules-visage pour les moments forts

ERREURS À ÉVITER :
→ Ciel blanc bouché (pas de fond plat gris — reprogrammer si nécessaire)
→ Voisins / voitures banales dans le champ
→ Ombres dures sur le visage en plein soleil (utiliser réflecteur ou chercher l'ombre)
→ Bruit de fond incontrôlable (soufflerie, chantier) — tester l'audio avant de commencer

MATÉRIEL SPÉCIFIQUE :
□ Réflecteur 5-en-1 (or/argent/blanc) pour la lumière naturelle
□ Micro-cravate filaire ou Lavalier Bluetooth (éviter le vent dans le micro)
□ Bonnette anti-vent sur tous les micros
□ Stabilisateur pour les plans marchants
```

### Extérieur — Jardin / Jardinage

**Ambiance cible :** Aisée, propriétaire, calme — métaphore de la protection/culture
**Props validés :** Sécateur, cisailles, pelle, arrosoir, gants jardinage
**Tenue acteur :** Décontractée propre (pas de tenue de jardinage usée)

```
PLANS TYPES :
- Acteur taille des branches → plan moyen + insert sur les mains
- Acteur se redresse, regarde caméra → rupture de rythme = accroche
- Acteur prend une pelle (chute humoristique) → plan large
- Acteur se gratte la nuque / fatigué → plan rapproché réaction

SYNCHRONISATION TEXTE / ACTION :
→ Le geste commence 0.5s AVANT le mot clé (anti-effet robotique)
→ On entend les sons du jardinage en fond — ne pas couper le son ambiance
→ Les chutes physiques (prendre la pelle) se font lentement, regardent vers caméra

CONTINUITÉ :
→ Toujours noter la position des props entre les prises
→ Si plusieurs jours de tournage : photo du décor avant de partir
```

### Extérieur — Terrain de Golf

**Ambiance cible :** Cadre de vie premium, sérénité, précision — métaphore de la stratégie
**Moments clés à filmer :** Setup de la balle / swing / balle qui part / réaction
**Tenue acteur :** Golf classique (polo + pantalon chino ou short golf)

```
SÉQUENCE DE TOURNAGE GOLF :
1. Filmer d'abord tous les plans marchants (conversation face caméra)
2. Ensuite les setups de balle (plan moyen + plan large)
3. Les swings (plan latéral pour voir le geste + plan face pour le regard)
4. Les réactions après swing (rapproché visage)
5. Le "balle dans le trou" en dernier (si applicable)

PLANS TYPES :
- Plan latéral swing → on voit la technique + le corps
- Plan face → regard pendant le swing, expression
- Insert balle + club → le sol, la balle, la tête du club
- Plan large → acteur + fairway + ciel → establishes le lieu
- Plan marchant → acteur se déplace vers la balle / vers le trou

ERREURS À ÉVITER :
→ Groupe de joueurs qui passe dans le champ
→ Son du club qui couvre la voix (ajuster micro + distance)
→ Lumière rasante trop dure sur le visage (choisir position du soleil)
→ Bruit de fond parcours (tondeuse, voiturettes)

TIMING TECHNIQUE GOLF :
→ Le swing dure ~1.5s — le texte de l'accroche doit être AVANT ou APRÈS
→ Exception : si le texte est court (<5 mots) → peut se dire PENDANT le swing
→ La réaction post-swing (regard, sourire) = moment parfait pour le CTA
```

### Extérieur — Salle de Billard

**Ambiance cible :** Club privé, ambiance feutrée, jeu de précision — métaphore stratégie/précision
**Props :** Queue de billard, boules de billard (dont la noire pour la chute), table verte
**Tenue acteur :** Smart casual (veste sans cravate / chemise ouverte)

```
SÉQUENCE DE TOURNAGE BILLARD :
1. Plans d'introduction : acteur tient la queue, cadrée 3/4
2. Plans de préparation : acteur se place pour le tir
3. Plans de tir : différents angles pour chaque coup
4. Réactions entre les tirs : moments de texte rapproché
5. "Casse" en début = ouverture dramatique
6. Boule noire en dernier = chute visuelle forte

PLANS TYPES :
- Plan contre-plongée légère → valorise l'acteur, voit la table
- Insert sur les boules → couleur, trajectoire
- Plan latéral tir → on voit la technique + l'expression
- Plan rapproché visage → après un bon coup (réaction)
- Plan large table + acteur → établit la maîtrise

SYNCHRONISATION CLÉS :
→ Les bons coups sont sur les points forts du script ("Pas mal celle-là !")
→ Les "ratés" ou hésitations renforcent l'humour — les garder
→ La boule noire dans le trou = dernier mot du script
```

### Intérieur — Bureau Expert / Conseiller

**Ambiance cible :** Professionnel, expertise, confiance — crédibilité immédiate
**Décor :** Bureau rangé, étagères avec livres, diplômes flous en fond, lumière chaude
**Tenue acteur :** Costume veste sans cravate OU chemise bien repassée

```
ÉCLAIRAGE BUREAU :
→ Lumière principale : côté (fenêtre naturelle ou softbox latérale)
→ Lumière de remplissage : réflecteur côté opposé (pas de fill trop fort)
→ Lumière de fond : ampoule chaude sur les étagères (bokeh chaleureux)
→ Éviter les néons du plafond (teinte verte, aplati le visage)

ANGLES CAMÉRA BUREAU (à alterner au montage) :
- Face légère hauteur yeux → plan principal
- 3/4 droit → légère personnalité
- 3/4 gauche → variation
- Rapproché épaules → moments d'emphase
- Plan large bureau → établit le cadre en ouverture

TECHNIQUE DE JEU BUREAU :
→ L'acteur parle à une personne précise (client imaginaire en face de lui)
→ Regard caméra 80% du temps, pause regard bas 20% (réfléchit)
→ Les mains peuvent être sur le bureau (posées / geste discret)
→ Le clin d'œil final = doit être naturel, pas forcé
```

## SPÉCIFICATIONS TECHNIQUES PAR FORMAT

### Format Vertical (TikTok / Reels / Shorts)
```
Ratio         : 9:16
Résolution    : 1080 × 1920 minimum
Frame rate    : 25fps ou 30fps
Zone sécurisée : Laisser 15% en haut (UI TikTok) et 20% en bas (CTA/liens)
Texte à l'écran : Police ≥ 32px, contraste fort, durée ≥ 1.5s par ligne
```

### Format Horizontal (YouTube / Meta Feed)
```
Ratio         : 16:9
Résolution    : 1920 × 1080 minimum
Zone sécurisée : 5% de marge sur tous les côtés
```

### Format Carré (Meta Feed / LinkedIn)
```
Ratio         : 1:1
Résolution    : 1080 × 1080 minimum
Acteur cadré  : Buste-épaules (pas de plan large)
```

## CHECKLIST MATÉRIEL PAR TYPE DE TOURNAGE

### Tournage UGC (1 caméraman + 1 acteur)
```
□ Smartphone récent (iPhone 14+ / Samsung S23+) ou caméra Sony ZV-E10
□ Trépied ou mini-trépied flexible (Joby GorillaPod)
□ Stabilisateur (DJI OM 6 si smartphone)
□ Micro-cravate filaire (Rode SmartLav+) ou sans fil (DJI Mic)
□ Bonnette anti-vent (obligatoire en extérieur)
□ Batterie externe chargée
□ Carte mémoire 128Go minimum (vidéo haute résolution)
□ Réflecteur 5-en-1 (lumière extérieure)
□ Application de télésouffleur si script long (Teleprompter app)
□ Écouteur bluetooth pour se souvenir du texte (si pas de télésouffleur)
```

### Tournage Studio / Bureau (setup qualité prod)
```
□ Caméra : Sony A7III / Canon R6 / Blackmagic Pocket
□ Objectif : 50mm f/1.8 ou 85mm f/1.8 (bokeh naturel)
□ Trépied solide
□ Softbox latérale (lumière principale) + réflecteur (fill)
□ Lumière de fond (ampoule chaude 2700K)
□ Micro perche (Rode NTG3) ou micro-cravate (Rode Lavalier GO II)
□ Interface audio (Focusrite Scarlett Solo si micro XLR)
□ Moniteur externe (voir la mise au point)
□ Télésouffleur avec support (Ulanzi ou Parrot)
□ Fond / étagères / plantes (éléments de décor)
```

### Tournage Sport Extérieur (golf / activité)
```
□ Caméra avec stabilisation IBIS (Sony ZV-E10 / GoPro Hero 12)
□ Objectif 24-70mm (polyvalent pour les différents plans)
□ Stabilisateur motorisé (si plans marchants)
□ Micro-cravate sans fil (DJI Mic) — câble gênant en mouvement
□ Bonnette anti-vent OBLIGATOIRE
□ ND filter (si plein soleil — évite la surexposition)
□ Batterie de rechange (tournage long en extérieur)
□ Réflecteur 5-en-1 + assistant pour tenir le réflecteur
□ Bâche légère en cas de pluie soudaine (matériel)
```

## ORDRE DE TOURNAGE RECOMMANDÉ

### Principe général
```
1. ACCROCHES EN PREMIER
   → Énergie maximale de l'acteur
   → 3 versions A/B/C de suite pour garder la cohérence
   → Si l'accroche rate, le reste ne sert à rien

2. CORPS COMMUN ENSUITE
   → Plus long, peut être segmenté
   → L'acteur est chauffé, plus naturel

3. CHUTE / CTA EN DERNIER
   → Moment mémorable → garder de l'énergie pour ça
   → La chute doit être tournée avec enthousiasme

4. PLANS DE COUPE / INSERTS À PART
   → Après le texte principal
   → L'acteur peut répéter des gestes sans parler
```

### Si plusieurs vidéos dans la même journée
```
→ Grouper par DÉCOR (pas par vidéo)
→ Tous les plans "devant la maison" → puis "dans le jardin" → etc.
→ Changer de tenue entre deux vidéos distinctes (même journée, look différent)
→ Pause toutes les 90 minutes (fatigue vocale et cognitive)
→ Tourner les vidéos les plus exigeantes avant 14h
```

## RÈGLES D'OR DU TOURNAGE TERRAIN

```
1. TOUJOURS tester l'audio avant la première prise
   → Casque dans les oreilles pendant le tournage
   → Écouter le playback de la prise 1 avant de continuer

2. TOUJOURS faire minimum 3 prises de chaque plan
   → Prise 1 : chauffe
   → Prise 2 : bonne
   → Prise 3 : sécurité

3. NOTER les bonnes prises sur le moment
   → "Plan 3 / Prise 2 = KEEPER" → dit à voix haute ou noté sur téléphone
   → Évite des heures de dérushage inutile

4. NE JAMAIS couper quand l'acteur finit de parler
   → Laisser 3 secondes de silence après la dernière phrase
   → Donne de la marge au montage

5. TOUJOURS tourner les transitions physiques
   → L'acteur part, s'éloigne, se retourne : tourner même si pas dans le script
   → Le monteur choisira ce qui marche

6. SAUVEGARDER pendant le tournage
   → Upload en cloud ou copie sur disque dur externe avant la fin de journée
```
